1 Komitmen Privasi

Cabang Dinas Kehutanan (CDK) Wilayah V Garut ("kami") mengelola aplikasi Phonebook dengan prinsip penghormatan tinggi terhadap privasi data pribadi aparatur, penyuluh kehutanan, tenaga teknis, serta pengguna layanan. Kebijakan Privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, menyimpan, dan melindungi informasi pribadi Anda saat menggunakan aplikasi mobile Phonebook, layanan backend API, bot Discord developer, dan sistem integrasi terkait.

2 Informasi yang Kami Kumpulkan

Untuk menunjang operasional kedinasan dan pelaporan kegiatan, sistem kami memproses jenis data berikut:

  • Informasi Profil & Akun: Nama lengkap, alamat email resmi, jabatan, unit kerja, foto profil (dari akun Google jika menggunakan SSO Google), dan nomor WhatsApp aktif.
  • Data Laporan Kegiatan Lapangan: Judul kegiatan, kategori kegiatan kehutanan, tanggal pelaksanaan, deskripsi rinci, jumlah peserta/anggota masyarakat yang didampingi, serta lokasi koordinat geografis jika disematkan.
  • Foto Dokumentasi Lapangan: Foto-foto dokumentasi kegiatan yang diunggah melalui kamera perangkat atau galeri ponsel, disimpan beserta metadata resolusi dan rasio aspek.
  • Data Laporan Masalah & Tiket Pengaduan: Judul kendala teknis, kategori bug, deskripsi masalah, nomor WhatsApp kontak darurat pelapor, kode tiket unik (misal: TKT-202611...), dan tanggapan/solusi pengembang.
  • Data Teknis Perangkat & Sesi: Model perangkat, versi sistem operasi (Android / iOS), alamat IP jaringan, status otentikasi sesi token, serta data cache luring yang tersimpan aman di database lokal SQLite perangkat.

3 Tujuan Penggunaan Informasi

Data yang dikumpulkan dipergunakan semata-mata untuk kepentingan kedinasan dan keandalan sistem:

  • Memverifikasi identitas pengguna dan memberikan hak akses sesuai jabatan atau unit kerja.
  • Menyusun laporan kinerja kegiatan lapangan resmi yang dapat diekspor menjadi format dokumen cetak resmi instansi.
  • Melakukan sinkronisasi data dua arah antara penyimpanan lokal offline (SQLite) dengan cloud database server saat sinyal internet tersedia.
  • Menangani kendala operasional atau bug aplikasi yang dilaporkan pengguna secara langsung kepada tim developer.

4 Privasi Integrasi Bot Discord Pengembang

Kepatuhan Privasi Discord API (Discord Privacy Policy Compliance)
Bot Discord Phonebook hanya beroperasi di server internal pengembang yang telah ditentukan dan dibatasi aksesnya hanya untuk administrator dan tim pemeliharaan sistem resmi CDK Wilayah V Garut.

Terkait interaksi bot Discord:

  • Informasi yang Diteruskan: Ketika pengguna mengirim "Laporkan Masalah", hanya ringkasan masalah (nama pelapor, email, nomor WhatsApp untuk konfirmasi tindak lanjut, judul bug, dan deskripsi) yang dikirimkan ke kanal Discord pengembang.
  • Aksi Penyelesaian: Saat pengembang menekan tombol interaktif Discord (ACC / Tolak / Selesai) dan mengisi alasan penyelesaian, catatan tersebut dicatat ke database cloud Supabase dan dikirimkan kembali ke pengguna sebagai status penanganan resmi.
  • Batas Akses Data: Bot Discord Phonebook tidak membaca riwayat obrolan pribadi pengguna di Discord, tidak mengumpulkan daftar anggota server di luar kebutuhan operasional, dan tidak menyimpan pesan Discord di luar konteks tiket pengaduan Phonebook.

5 Komunikasi Melalui WhatsApp Gateway (Fonnte)

Aplikasi Phonebook mengintegrasikan gateway WhatsApp resmi pihak ketiga (Fonnte API) untuk pengiriman notifikasi instan:

  • Nomor WhatsApp hanya digunakan untuk mengirimkan notifikasi status tiket pengaduan (ketika tiket diterima, ditolak, atau selesai ditangani) dan pengingat jadwal tugas kehutanan.
  • Nomor WhatsApp pengguna dijaga kerahasiaannya dan tidak dipublikasikan ke publik atau dibagikan ke pihak ketiga lainnya.
  • Sistem tidak pernah mengirimkan pesan berantai, spam, atau promosi komersial.

6 Keamanan & Lokasi Penyimpanan Data

Kami menerapkan standar keamanan teknis berlapis guna melindungi integritas data Anda:

  • PostgreSQL Supabase (Enterprise Cloud): Seluruh data pengguna, jadwal, laporan kegiatan, dan tiket disimpan di infrastruktur cloud database PostgreSQL terkelola Supabase dengan enkripsi saat istirahat (encryption-at-rest) dan enkripsi saat transit (SSL/TLS).
  • Enkripsi Komunikasi: Seluruh pertukaran data antara aplikasi Flutter dan backend Laravel berjalan di atas protokol aman HTTPS dengan sertifikat TLS modern.
  • Kriptografi Ed25519: Seluruh permintaan webhook dan interaksi Discord divalidasi keabsahannya dengan kunci kriptografis publik Ed25519.
  • Keamanan Kredensial: Kata sandi di-hash menggunakan algoritma bcrypt modern berstandar industri. Bot token dan kunci API backend disimpan secara ketat di environment variable serverless yang terisolasi dan tidak pernah diekspos ke frontend.

8 Hak & Akses Pengguna

Setiap pengguna memiliki hak penuh atas data pribadi mereka:

  • Hak Akses & Pembaruan: Anda dapat memeriksa dan memperbarui informasi nama, foto profil, dan nomor WhatsApp kapan saja melalui menu Pengaturan Profil di aplikasi Flutter.
  • Hak Ekspor Data: Pengguna berhak mengunduh seluruh arsip laporan kegiatan yang dibuat dalam format dokumen cetak resmi instansi.
  • Hak Koreksi & Penghapusan: Pengguna dapat mengajukan permohonan perbaikan data yang keliru atau penghapusan akun dinas melalui administrator sistem CDK Wilayah V Garut.

9 Retensi & Penghapusan Data

Data laporan kegiatan lapangan disimpan sesuai kebutuhan arsip kinerja aparatur pemerintah daerah. Jika akun dinas dinonaktifkan atau dihapus atas instruksi instansi, data otentikasi pribadi akan dihapus secara permanen dari server aktif, sedangkan arsip laporan kegiatan yang telah disetujui akan diarsipkan sesuai regulasi kearsipan instansi kehutanan.
